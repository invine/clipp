Final qualification uses one frozen integration commit after all code changes. Android native provenance binds the acceptance APK pair to that exact commit, checkout, lockfile and installed dependency inventory; each API 31/33/34/35/36 receipt binds to that pair. Earlier native receipts cannot be transplanted to a later source. An authorized debug install on a fresh owned emulator then confirms product APK bytes, certificate, version, launch/readiness and no-op replay. The final evidence summary must name the source hash, profile hash, Node/npm/JDK/SDK versions, selected destinations, plan/run IDs, receipt paths and any unperformed acceptance. Controlled Play tests prove recovery logic; they do not prove a real release. Record actual Play internal publication as **not run**, with its owner and next action, until separately authorized and read back from the selected application/track.
