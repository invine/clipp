# Project operations

Select the Clipp and relay repository roots explicitly for work involving both. Each Git repository has its own branch tip; paths in the companion repository are resolved against that selected root.

| Task                        | Authoritative source                                                                                                                                                                                                                                                                                                   |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Build and verify            | Root [npm scripts](../../package.json), each runtime's `package.json`, and [pre-commit hook](../../.husky/pre-commit). Current required check before a code commit: `npm run check`; routine verification inventory is in the [workflow plan](../../.scratch/agent-workflow/README.md#routine-verification-inventory). |
| Runtime acceptance          | [Electron](../electron-relay-acceptance.md), [Android native](../android-managed-relay-native-acceptance.md), and [Chrome](../../apps/extension/README-managed-relays.md). A web build does not establish native or forced relay transfer acceptance.                                                                  |
| Operator setup              | In the selected relay root, open `docs/operator/README.md`; use its wizard help and separate mutation gates. Private configuration remains outside Git.                                                                                                                                                                |
| Architecture and vocabulary | [Glossary](../../GLOSSARY.md), [architecture map](../agent-guide.md), [ADRs](../adr/) and [accepted transport fallback](../adr/0012-relay-transport-fallback-and-concurrent-sessions.md). Open the relevant settled feature spec under `.scratch/`.                                                                    |
| Coordinate or resume work   | [Implementation, decisions and recovery](workflow.md) owns the decision checkpoint, coordinator claims, dispatch, integration and resolution procedure. Use the [canonical tracker](../../.scratch/agent-workflow/README.md) and [current run record](../../.scratch/agent-workflow/run.md) for this effort.           |
| Recover prior work          | Follow [resume and recover](workflow.md#resume-and-recover) using current Git and canonical records. In the selected relay root, `docs/operator/consolidation.md` records dated 2026-10-04 recovery artifacts; preserve existing work before cleanup.                                                                  |

Use [bounded lookup](source-lookup.md) to list or search a selected scope. Start with `docs`, a named source directory, or an exact task directory rather than scanning runtime data. Lookup results identify sources; they do not grant approval for publication, deployment or live acceptance.
