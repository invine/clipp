# UI behavior story coverage

This index points to evidence delivered by the earlier implementation tickets.
`tests/ui-behavior/` is the mounted Playwright suite against the production UI
and real UI behavior with scripted effects; `tests/harness/ui-behavior/` hosts
the corresponding manual scenarios. Unit and adapter tests are called out where
they cover a story that should not be duplicated as a UI journey.

Required mounted journeys are accounted for above: Pairing and Trust Request
outcomes, scan recovery/cancellation, all four connection presentations,
Share Now and reuse, History mutations, naming and revocation, relay actions,
settings recovery, notification return, Background Continuity, identity-reset
presentation, Identity Rotation, stale completions and runtime replacement.

Native and live-device acceptance remains independent of these controlled
journeys. See the repository [operations guide](../../../docs/agents/operations.md)
for runtime acceptance procedures.
