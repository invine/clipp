# 04: Settings view

**What to build:** Organize Clipp's existing settings into the approved responsive Settings view, making real applied values, available actions and recovery information easy to find.

**Blocked by:** 01 — Responsive workspace and Clipboard History.

**Status:** ready-for-agent

- [ ] Existing appearance preferences, including System, Light and Dark, and applicable Auto Sync and notification controls remain available with actual applied, pending, failure and recovery states.
- [ ] Local retention, Clip Sharing Lifetime, pin exemptions and clear-history review remain available with their existing semantics; no sample history limit becomes a product policy.
- [ ] Managed relays remain empty when unconfigured, and existing relay, identity, recovery and platform-specific controls remain reachable where supported.
- [ ] Disabling Auto Sync retains local capture and Clipboard History; no change is made to sharing, identity or transport contracts.
- [ ] Test observable shared UI and affected application UI in both themes and responsive layouts with realistic fixtures; do not run connection tests or tests that send Clips.
