## Reproduction

Build Electron from the source receipt, then run `node .scratch/ux-study/electron-evidence/harness.cjs` from the repository with an interactive terminal. The harness creates a new temporary profile and memory clipboard, applies existing relay-only acceptance isolation, and loads the actual built main process. Do not substitute an operator profile. It accepts study JavaScript on stdin; use short commands such as `await eval(await fs.readFile(path.join(dir,'phase-sizes.js'),'utf8'));` because the macOS terminal input buffer truncates long lines.

The initial native observations used the empty profile, an in-memory string `UX study: local capture with no configured relay.`, the built UI, and the actual constructed tray MenuItem callbacks. They precede any IPC mock. Open the logo drawer, Show my QR, close the dialog, capture the text, Copy it, and Add relay → Save with an empty endpoint. Native font failure occurred without request interception. The screenshot report contains the individual steps and dimensions.

The fonts-loaded comparison used the stylesheet already imported by Clipp and its five font URLs. `font-manifest.json` retains the exact upstream URLs and hashes. Public font downloads were saved as `/private/tmp/clipp-ux-fonts.css` and `/private/tmp/clipp-ux-{material-symbols,roboto300,roboto400,roboto500,roboto700}.ttf`; they are not bundled here or installed into the OS. Restore those exact assets before replaying `phase-fonts.js`, or deliberately retain failed-font behavior. That phase supplies the upstream stylesheet by request interception; it does not edit app CSS.

Run phases in order: `phase-fonts.js`, `phase-sizes.js`, `phase-controls.js`, `phase-dense.js`, `phase-final-checks.js`, `phase-native-capture.js`, `phase-actions.js`. `fixture.cjs` generates canonical public Peer IDs and fresh UUIDv4 Clip IDs; private keys are discarded. `fixture-public.json` is the actual recorded run, with its fixture clock. Most pending names are within 64 code points; the first deliberately exceeds that contract as a rendering stress value. Do not use that overlength name as evidence of accepted native validation. Mock relay endpoints do not identify live services.

`mock-bridge.cjs` substitutes public state/actions after native-only observations. This prevents fixture pairing/relay/account actions from contacting other devices or services. Never interpret a mocked action as actual network or storage success. Do not click QR Copy against an unprotected system clipboard: unlike native retained Copy, its `navigator.clipboard` path was not exercised here.

For the native tray checks, invoke the actual menu callback from `globalThis.__uxMenus`; this is an application MenuItem test, not proof of OS notification or tray-popup accessibility. Closing the window hides the study Dock. Following that check the harness restored **the study app's** Dock with `app.dock.show()` before more captures; otherwise a Playwright screenshot timed out. End with `await quit();` to close only the owned process.

## Measurement cautions

- Raw `observations.jsonl` is append-only capture data. `trace.jsonl` contains later command results. `evidence.jsonl` and `index.html` are generated by `node .scratch/ux-study/electron-evidence/summarize.cjs`.
- A ledger `pass` without a finding means successful capture/measurement, not an exhaustive UX pass. The report lists bounded successful flows and gaps explicitly.
- Early `dom.fullyVisibleCards` checked only viewport bounds. It overcounts cards clipped by their history scroller. Use later `geometry.visibility.fullCards`, which intersects all scrolling/clipping ancestors. DOM visibility metrics do not account for overlay occlusion; use them on unoccluded history views only.
- Playwright screenshots at non-1 zoom cropped the rendered content in this environment. Do not diagnose the apparent crop as an application defect. Use `native-reflow-320-collapsed.png`, `native-capture-reflow-320.png` and `native-capture-minimum-zoom2.png` plus geometry instead. Later capture phases use `webContents.capturePage()` and record native bitmap size.
- Font-assisted screenshots are rendering fixtures. Display scale stayed 2 throughout; DPR changes with page zoom. Native 1× display, other work areas, OS text scaling and live auth/notification/rotation acceptance were not run.
- Baseline source files remained identical to the inventory. The current receipt stores its own full tracked-diff hash rather than assuming the previous inventory's differently recorded diff hash matches.

The scripts are retained study tooling, not application changes or maintained test coverage. Replaying appends observations and generates a fresh isolated identity; use a new evidence directory if preserving this exact run.
