# Clipp UX implementation

**Owning repository:** client (Clipp)
**Canonical feature directory:** client:`.scratch/ux-implementation/`

Resume from [current.json](current.json) and the derived report, then open the selected numbered ticket:

```sh
node scripts/agent-status.mjs --entry client:.scratch/ux-implementation/current.json --local /absolute/ux-local.json --compact
```

Add `--json` for every scenario, evidence observation, blocker and exact authorization scope. The local configuration resolves `ux-active-run` outside disposable worktrees. Canonical issues own Status/Blocked by and existing claims; [catalog](catalog.json), [coverage](validation-coverage.md), [traceability](traceability.md) and [allocation](scenario-allocation.md) define scope rather than a second frontier.

Read [adoption and candidate gates](adoption.md) before preparing a candidate, dispatching37/38 or renewing evidence. [Current continuation](run.md) holds exceptions; [historical run](history/run-through-20261029.txt) preserves dated observations and failures. Scoped [decision records](decisions.md) retain their original limits. This metadata adoption supplies no new native pass or permission.
